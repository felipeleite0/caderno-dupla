# Caderno Dupla

Exercício introdutório de HTML desenvolvido em aula, com uma página estática usando título, parágrafos, lista de ingredientes e lista ordenada de preparo.

## Objetivo

- Praticar a estrutura básica de uma página HTML.
- Usar elementos de texto, listas não ordenadas e listas ordenadas.
- Registrar os primeiros exercícios de desenvolvimento web.

## Tecnologia

- HTML

## Arquivo principal

```text
index.html
```

## Observação

Este repositório representa um exercício inicial de aprendizagem. Por isso, ele é mais simples do que os projetos principais do perfil.
